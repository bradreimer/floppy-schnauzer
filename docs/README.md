# Documentation

This folder holds every document about Floppy Schnauzer, sorted by what the document does. Start
with the [guidelines](guidelines.md), then read the kind of document you need.

| Document or folder | What it holds | Read it when |
| --- | --- | --- |
| [guidelines.md](guidelines.md) | The seven rules that apply to every change | Before your first change |
| [development-workflow.md](development-workflow.md) | The steps from an idea to a release | Before you start a work item |
| [roadmap.md](roadmap.md) | What gets built, in what order | You plan the next piece of work |
| [status.md](status.md) | What's done, in progress, and next | You pick up the project after a break |
| [adr/](adr/README.md) | Architectural decisions and why they were made | You want to change how the project is built |
| [specs/](specs/README.md) | What each capability must do, with acceptance criteria | You change behavior |
| [knowledge/](knowledge/README.md) | Reference material: how things work today | You need to understand a part of the code |

Work items aren't documents. They're
[GitHub Issues](https://github.com/bradreimer/floppy-schnauzer/issues).

When documents disagree, the order of authority is: ADRs, then specs, then knowledge documents.
